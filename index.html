📚 How to Use

1. Grammar Format

Enter production rules in the format LHS → RHS. Use | to separate alternatives:

S → aS | bS | ε

Use → or -> as the arrow. Non-terminals are uppercase letters; terminals are lowercase (or digits/symbols).

2. Target String

Enter the string you want to derive. Use ε or leave blank for the empty string.

3. Max Steps

The maximum number of production rule applications. If the grammar is recursive, a bounded N prevents infinite loops.

4. Search Strategy

  • BFS — finds the shortest derivation first (recommended)
  • DFS — explores one path deeply before backtracking

5. Regular Grammar Rules

A right-regular grammar only allows rules of the form:

  • A → aB (terminal followed by non-terminal)
  • A → a (single terminal)
  • A → ε (empty string)

Note: This tool also supports context-free grammars for broader exploration.
